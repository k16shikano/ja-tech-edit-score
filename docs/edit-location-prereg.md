# 事前登録：文単位の編集箇所予測（edit location prediction）

登録日: 2026-07-30  
状態: **Phase 0・人間承認待ち**（本文書確定前に Phase 1 以降のコード・学習を開始しない）

## 1. 目的と非目的

### 目的

下書きの各文について、「職業編集者が手を入れた文か（`edited=1`）／表層がそのまま残った文か（`edited=0`）」を予測する。  
編集の良し悪し・意図・構成改善の判定はしない。

### 非目的（主張しないこと）

- 触られなかった文が良い文である、とは言わない
- 編集意図の分類はしない（同一箇所に複数意図が混ざる前提）
- Hard Eval 型の候補順位づけの代替にはしない
- 本命モデルの PR-AUC が偶然水準を超えただけでは「編集箇所予測に成功した」と言わない（**長さのみベースライン M0 を上回ること**が成功条件）

### 難試験の欠陥との関係

候補順位づけにあった非盲検・参照順位の設計依存・長さ交絡を、本実験では次で回避する。

- ラベルは下書き文と推敲後文の**表層対応**から機械的に作る（人手の「良い候補」順位を使わない）
- 評価は二値予測の PR-AUC 等（順位一致率ではない）
- 長さ交絡は M0 との比較と、M2 得点の文長残差で明示分解する

## 3. 文分割

既存の `scripts/sentseq_utils.py`（`SENTSEQ_SPLIT_VERSION=v1`）をそのまま使う。

- 段落: `\n\n+`
- 地の文: `[。！？][」』)]*`
- 見出し・箇条書き・コードフェンス内の行: 1 行 = 1 文
- 段落先頭文フラグ: `SentenceUnit.is_para_start`

`align_section_edits.py` 側の別分割器は使わない（sentseq 系と不一致のため）。

## 4. 表層正規化（不一致判定の前処理）

ラベル付けの直前に、下書き文・推敲後文の双方へ次をこの順で適用する。

1. Unicode NFKC
2. 改行・タブ・全角スペースを半角スペースへ置換
3. 連続空白を 1 個の半角スペースへ圧縮
4. 前後の空白を除去

正規化後の文字列が完全一致なら `edited=0` 候補。  
空白・改行のみの差は不一致に数えない（上記で吸収する）。

句読点の追加・削除、漢字かな変換、語順変更は不一致（`edited=1`）とする。

## 5. アライメント

### 類似度

下書き文ベクトル \(e_i\)、推敲後文ベクトル \(e'_j\)（凍結 `cl-nagoya/ruri-v3-30m`、`text_prefix="文章: "`、L2 正規化）について:

- コサイン類似度 \(c_{ij} = \langle e_i, e'_j \rangle\)
- 正規化編集距離 \(d_{ij} = \mathrm{Lev}(s_i, s'_j) / \max(1, |s_i|, |s'_j|)\)  
  （編集距離は正規化**後**の表層に対して計算）
- 結合スコア \(a_{ij} = c_{ij} - \lambda d_{ij}\)

\(\lambda\) は開発用書籍だけで選ぶ（探索範囲は §8）。

### 動的計画（単調・DTW 様）

コスト行列を \(-a_{ij}\)（大きい \(a\) が安い）とし、単調なパスで下書き列と推敲後列を対応づける。

許す対応タイプ:

| タイプ | 意味 |
|--------|------|
| 1-1 | 1 下書き文 ↔ 1 推敲後文 |
| 1-n | 1 下書き文 → 複数推敲後文（分割） |
| n-1 | 複数下書き文 → 1 推敲後文（結合） |
| delete | 下書き文に対応なし（削除） |
| insert | 推敲後文に対応なし（挿入。下書きラベルには使わない） |

パス上の各対応について、\(c_{ij} < \tau_c\) かつ \(d_{ij} > \tau_d\) のときは強制的に「対応なし」へ落とす。  
閾値 \(\tau_c, \tau_d\) は開発用書籍だけで選ぶ。

実装は新規（既存の `greedy_align` / SequenceMatcher は使わない）。外部 API は使わない。

### ラベル

下書きの各文:

- `edited = 1`: 削除、分割・結合への関与、または 1-1 対応先と正規化後表層が不一致
- `edited = 0`: 1-1 対応先と正規化後表層が完全一致

## 6. アライメント品質検証（Phase 1 ゲート）

1. **機械チェック（全件）**
   - 対応の単調性（下書き・推敲後のインデックスが非減少）
   - 分割・結合の収支（各文が高々一つの対応ブロックに属する）
   - 異常件数を報告書に載せる
2. **層化抽出 CSV（開発用書籍から 100 文対）**
   - 列: 対 ID、文インデックス、対応タイプ、コサイン、正規化編集距離、ラベル、文長（**本文なし**）
   - 層: 対応タイプ（1-1一致 / 1-1不一致 / 削除 / 分割 / 結合）ができるだけ均等
3. 曖昧ケースは件数と ID のみ列挙し、人手判定は保留のまま報告する

Phase 1 完了後、人間承認を待ってから Phase 2 へ進む。

## 7. 評価指標（固定）

すべて **文単位**。書籍 \(b\) 内の全下書き文をプールして算出する。

| 役割 | 指標 | 定義 |
|------|------|------|
| 主要 | PR-AUC | 平均 precision–recall 曲線下面積。実装: `sklearn.metrics.average_precision_score` |
| 副次 | ROC-AUC | `sklearn.metrics.roc_auc_score`（正例が 0 または全正例の冊は欠測とし、macro では当該冊を除外して明記） |
| 副次 | precision@k | 節（1 revision 対）ごとに \(k=\) その節の実編集文数。得点上位 \(k\) 件の適合率。節平均を冊内平均し、さらに micro/macro |
| 報告 | 正例率 | `edited=1` の割合（冊別・全体） |

集約:

- **micro**: 13 冊の全文明けて 1 つの PR-AUC（主要の参考）
- **macro**: 13 冊の PR-AUC の単純平均（**成功判定に使う**）

区間:

- 割合指標（正例率、precision@k の冊内平均など）: Wilson 95% 区間（冊別）
- モデル間差: 書籍を再標本化単位とする **対応付き bootstrap 100,000 回**。各複製で 13 冊から復元抽出して macro 指標差を再計算し、2.5/97.5 パーセンタイルを 95% 区間とする。乱数シードは `20260730` で固定。

## 8. モデルとハイパーパラメータ（nested）

### 共通

- 乱数シード: 学習 `20260730`、bootstrap `20260730`
- デバイス: CPU 可。GPU があれば使用可（結果はシード固定で再現を目指す）
- 外部 API 禁止。埋め込みはローカル `cl-nagoya/ruri-v3-30m` のみ（本実験で生成 LLM は使わない）

### 開発用書籍内のチューニング手順

開発用書籍の revision 対を **対 ID のハッシュ**で 80% train / 20% valid に分割（シード固定）。  
valid の PR-AUC が最大の設定を 1 組だけ採用し、以降変更しない。

探索はグリッド（全組合せ）。計算が重い場合は、先に粗いグリッド → 最良近傍のみ、の二段でもよいが、**採用した最終設定と探索ログをすべて残す**。

### M0（長さのみ・必須ベースライン）

特徴（文ごと）:

- \(L\): 正規化前の文字数（生表層。空白込み）
- \(L^2\)

モデル: `sklearn.linear_model.LogisticRegression`

| パラメータ | 探索範囲 |
|------------|----------|
| `C` | `{0.01, 0.1, 1.0, 10.0, 100.0}` |
| `class_weight` | `{None, balanced}` |
| `penalty` | `l2` 固定 |
| `solver` | `lbfgs` 固定 |
| `max_iter` | `2000` 固定 |

特徴の標準化: train fold のみで mean/std を推定し valid/test に適用（冊外漏えい禁止）。

### M1（表層特徴）

M0 の特徴に加え:

| 特徴 | 定義 |
|------|------|
| `sent_pos` | （節内 0-based 文番号）/ max(1, 節内文数-1) |
| `para_pos` | 段落内の同様の相対位置 |
| `is_para_start` | 0/1 |
| `kanji_rate` | Unicode 漢字 / 文字数 |
| `katakana_rate` | カタカナ / 文字数 |
| `comma_count` | `、` と `,` の個数 |
| `ending_taigen` | 体言止め粗い判定: 正規化後が助詞・句点類で終わらず、かつ末尾が漢字・カタカナ・英数字 |
| `ending_dearu` | 末尾が `である` / `だ` / `だった` / `だろう` 系（簡易辞書） |
| `ending_desumasu` | 末尾が `です` / `ます` / `でした` / `ました` 系 |
| `starts_with_conn` | 先頭が接続詞リストに一致（「しかし」「また」「一方」「さらに」「なお」「ただし」「ところで」「すると」「つまり」「したがって」等、固定リストをコードに埋め込み） |

モデル: M0 と同じロジスティック回帰・同じ `C` / `class_weight` グリッド。

### M2（本命・文ベクトル列）

構造は `pref-sentseq` を流用し、**各文位置の出力からロジット**を出す（`[DOC]` 集約は使わない）。

固定アーキテクチャ（探索しない）:

| 項目 | 値 |
|------|-----|
| 埋め込み | 凍結 `cl-nagoya/ruri-v3-30m` |
| `d_model` | 256 |
| `nhead` | 4 |
| `num_layers` | 2 |
| `dim_feedforward` | 512 |
| `dropout` | 0.1 |
| `max_sents` | 128（超過は先頭から切り捨て。切り捨て文は評価から除外し件数を報告） |
| 位置埋め込み | 文位置 1..S |
| 段落開始埋め込み | `is_para_start` に加算 |
| 頭 | 各位置 `Linear(d_model → 1)` |
| 損失 | 重み付き BCE。正例重み \(w_+ = N_-/N_+\)（学習 fold 内）、負例重み 1 |

探索（開発用 valid の PR-AUC）:

| パラメータ | 探索範囲 |
|------------|----------|
| `lr` | `{1e-4, 3e-4, 1e-3}` |
| `epochs` | `{5, 10, 20}` |
| `batch_size`（節単位） | `{8, 16}` |
| weight decay | `{0.0, 0.01}` |

最適化: AdamW。勾配クリップ 1.0。

推論得点: ロジット（高いほど `edited=1` 側）。閾値は PR-AUC には不要。precision@k は得点順位のみ。

## 9. 成功・失敗の判定（固定）

主比較: **macro PR-AUC(M2) − macro PR-AUC(M0)**

対応付き bootstrap 95% 区間（書籍単位、100,000 回）について:

- 区間の下限が **0 より大きい** → 「文長以外の信号がある」と結論する
- そうでない → 「編集箇所は本データでは表層長で説明される」と結論する（これも正の結果として報告する）

M1 は参考比較（表層非長特徴の寄与）。成功判定には使わない。

追加報告（判定には使わない）:

- macro PR-AUC(M2) − macro PR-AUC(M1) の bootstrap 区間
- M2 の文長線形残差得点の PR-AUC と、それと M0 の差の bootstrap 区間

## 10. Phase 3 の交絡・切除（方式固定）

### 長さ交絡の分解

各 LOPO 保留冊内で、M2 の文得点 \(s\) を文長 \(L\) へ線形回帰し、残差 \(s - \hat{s}(L)\) を得点として PR-AUC を再計算する。  
回帰係数は**その保留冊の文だけ**で推定する（他冊の情報を入れない）。

### 切除試験（学習し直しなし）

採用済み M2 の重みを固定したまま、評価時だけ次を行う。

| 条件 | 操作 |
|------|------|
| (a) 文順シャッフル | 各節内で文ベクトル列・位置 ID・段落フラグを同じ置換でシャッフルして前向き計算。シャッフルシードは対 ID 由来で再現可能 |
| (b) 段落開始埋め込み除去 | `para_start_emb` の加算を 0 にする |

各条件の macro PR-AUC と、本条件との差を書籍単位 bootstrap で報告する。

### 誤り分析（本文なし）

偽陰性・偽陽性について、文長分布・節内位置分布・段落先頭率のみ集計する。
