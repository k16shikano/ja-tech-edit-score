# 学習用データ D と区間評価器 f(x,y) の実験計画

教師データ D（800 行）を固定し、下書き x と候補 y から f(x,y) を学ぶ。BRIEF の正式採用評価器（pref-sentseq-section-triples）の置き換え候補として、この実験だけの採否を決める。

データの作り方は [DATA.md](DATA.md)。教師 D の固定内容は変えない。

## 1. 測ること

下書き x に対し、候補 y が編集者の判断 J(x) をどれだけ実現しているかを、スカラー f(x,y) で表せるか。

固定点:

- f(x, x) = 0（g(x,y) − g(x,x) の形で保証）
- 人間の推敲 y に対して f(x,y) = 1（D の人間 200 行で教える）

位置ラベル（Qwen 生成 600 行）:

| 位置 | 意味 | 行数 |
|------|------|------|
| a | 劣化 | 267 |
| b | 下書きに相当 | 165 |
| c | 改善だが人間ほどではない | 118 |
| d | 人間の推敲と同程度 | 50（文字列一致 27、別表現 23） |

人間の推敲 200 行は位置 d。D 合計 800 行。

## 2. 立てる仮説

**H1（変化量からの独立）**  
位置 a または c に限定した Qwen 生成行について、f と文字数差・編集距離の偏相関が 0 に近い。ナイーブな BT（変えた量＝良い）なら、a と c は編集量で分離できないデータなので破れる。

**H2（Qwen 生成内の符号分離）**  
同一下書きの Qwen 生成のうち、位置 a では f < 0、c では f > 0 が、偶然より高い割合で成り立つ。

H1・H2 が主判定。区間所属の全体准确率は副次とする（後述の自明行を含むため）。

## 3. モデル

### 3.1 主モデル

- ベース: `sbintuitions/modernbert-ja-310m`（315M、全パラメータ更新）
- 入力: 下書き x と候補 y を tokenizer の二文入力（クロスエンコーダ）
- 出力: g(x,y) = 分類ヘッド 1 次元。f(x,y) = g(x,y) − g(x,x)
- 損失: 区間損失（a < 0、b ≈ 0、c ∈ (0,1)、d ≈ 1）。D 800 行のみ。第二教師系統なし
- 成果物: `outputs/pref-d-modernbert/`

### 3.2 対照

同じ D・同じ損失・同じ f の形で、次を 1 本ずつ並べる。

| 対照 | エンコーダ | 入力 |
|------|-----------|------|
| ruri 凍結 | `cl-nagoya/ruri-v3-30m` 凍結 | x と y を別々に全文埋め込み、差分特徴＋線形層 |
| （任意）D-600 | ModernBERT 主モデルと同型 | 教師から人間 200 行を除いた 600 行のみ |

ruri 対照は「検索向け bi-encoder をベースにした場合」の下限。D-600 は d 200 行が著者判別の捷経になっていないかを見る ablation。

## 4. 学習

| 項目 | 値 |
|------|-----|
| 教師 | `data/d/dataset.jsonl`（800 行固定） |
| 分割 | 下書き 200 件を 5 分割（各 40 下書き）。`data/d/folds/` |
| epoch 上限 | 20 |
| epoch 採用 | **fold 0 の valid 160 行だけ**で区間所属（後述の主評価部分集合）が最大の epoch を選び、fold 1–4 も同じ epoch 番号を使う |
| 最適化 | AdamW |
| 学習率（エンコーダ） | 5e-6 |
| 学習率（新規ヘッド） | 1e-4 |
| weight decay | 0.01 |
| warmup | 10% |
| batch | 16 行（forward 32 ペア: (x,y) と (x,x)） |
| 精度 | bf16 |
| max_length | 1024（下書き＋候補の合計、90 パーセンタイル 801 文字） |
| 乱数 `--seed` | 0（分割・初期化） |

Makefile 入口（実装後）:

```text
make pref-d-data
make pref-d-modernbert
make eval-pref-d-modernbert
```

## 5. 評価

### 5.1 手順

1. 5 分割の各 fold で、valid 160 行（40 下書き × 4 行）に out-of-fold の f を付ける
2. 5 fold 分を連結し、800 行すべてに 1 回ずつ held-out スコアが付く
3. 主指標はこの 800 行の連結結果から、部分集合ごとに集計する

### 5.2 部分集合（採否に使う順）

**主評価 A — Qwen の a と c（385 行）**  
y_kind が qwen_* かつ position が a または c。

- a（267）: f < 0 の割合
- c（118）: f > 0 の割合
- 二者合わせた符号一致率

これが H2。BT 系が破った「手が入っていれば正」との差は、ここで見る。

**主評価 B — H1（118 行、c のみ）**  
position c の Qwen 生成行について、下書きからの文字数差・正規化編集距離と f の Spearman 相関。位置 a でも同様に出すが、件数が多い a（267）を H1 の主報告とする。

**副次 — 別表現 d（23 行）**  
Qwen 生成で position d かつ y が人間の推敲と文字列不一致（人手判定 23 行）。f ≈ 1（|f−1| ≤ ε）の割合。編集者と同等だが表現が違う例の上限。

**参考 — 構造上 0（165 行）**  
position b。f(x,y)=g(x,y)−g(x,x) により y≈x なら f≈0 になりうる行。採否には使わない。学習安定の確認用に割合だけ記録する。

**参考 — 天井 d**  
- 人間 200 行: |f−1| ≤ ε
- Qwen 生成で y が人間の推敲と一致（27 行）: |f−1| ≤ ε

人間 200 行が高いだけでは H2 の成功とは言わない（著者判別の捷経）。主報告からは外し、参考に置く。

### 5.3 閾値

区間所属の ε = 0.25（b: |f| ≤ ε、d: |f−1| ≤ ε）。c は 0 < f < 1（端点 ε 内は所属とみなさない）。

### 5.4 採否の読み方

| 結果 | 解釈 |
|------|------|
| 主評価 A が BT 以上（a で f<0、c で f>0） | 符号分離は改善 |
| H1 で a/c 層内の相関が BT より低い | 編集量への依存が弱い |
| 主評価 A は良いが人間 d 200 だけ高い | 著者判別。D-600 ablation で確認 |
| 構造上 0 の 165 行だけ高い | 指標設計の確認。採否に使わない |
| ModernBERT ≈ ruri | 全更新より入力形（クロスエンコーダ）の効果が主 |

### 5.5 この実験で見ないもの

- A1 valid 210 の draft≻gold 件数
- B 検証 50 のブラインド一致
- pref-sentseq-section-triples との直接勝率比較

これらは別線の指標。D 実験の成否とは切り離す。

5. 主評価 A・H1・副次 23 行を `eval_cv_report.json` に集約
