日本語推敲を採点する君

下書きを基準に、推敲がどれだけ「良く」なったかをマージン（点差）で測ります。 良さの基準は、人間（鹿野）による推敲例 651 ペアから算出しています（したがって絶対的な基準ではありません）。

利用上の注意

  • このモデルでは「悪化したか」を評価できません （主軸の採点は「推敲で悪くなることはない」という想定に近いので、変更があると正の評価値になりやすい）。 そのため、下書きと推敲を入れ替えて指定しないでください。
  • 入力した文章はモデルによる評価計算のためにサーバーに送られるので注意してください （サーバーに長期間保存されたり学習に使ったりされることはありません）。
  • 入力できるのは8000文字まで。
  • IPアドレス単位で試行回数に制限を設けています（集合住宅とかでは注意してください）。
  • 仕組みの説明とコードは GitHub リポジトリ を参照。
  • 恒久的なサービスの予定はないので、ある日突然、予告なく中止します（決定事項）。
